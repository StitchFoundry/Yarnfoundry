# YarnFoundry v0.2.0 (draft release notes)

Suggested version: **v0.2.0** (changes since v0.1.0). Draft for the owner to approve; no version bump, tag or release is made by this PR.

- **3D import:** STL and OBJ files, with a closed-mesh check and size and units handling.
- **Feedback link** inside the app.

## Fixed / behind the scenes
- More reliable automated builds (package mirror fallback and retries).
